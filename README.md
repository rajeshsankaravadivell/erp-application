# ERP Application

A comprehensive Enterprise Resource Planning (ERP) system built with modern web technologies.

## Features

- Dashboard/Home
- Inventory Management
- Sales/Order Management
- Purchase/Procurement
- Accounting/Finance
- Employee Management (HR)
- Customer Relationship Management (CRM)
- Reports & Analytics

## Project Structure

- `frontend/` - React-based user interface
- `backend/` - Node.js/Express API server
- `docs/` - Documentation and specifications

## Getting Started

Please refer to the individual frontend and backend documentation for setup instructions.

## Modules Overview

This ERP system includes all essential modules for business operations management.
